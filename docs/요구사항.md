# markDown — 요구사항·설계안 (2026-10-03)

## 1. 형태
Windows 데스크톱 앱, Python + PySide6 (uv로 관리, 나중에 exe로 묶을 수 있음)

## 2. 화면 (세 칸, 칸 사이 기둥을 잡아 크기 조절)

```
┌────────────┬──────────────────┬──────────────────┐
│ 파일 탐색기 │ 편집기(원본)      │ 뷰어(미리보기)    │
│ ☑ a.md     │ # 제목            │ 제목              │
│ ☐ b.md     │ 본문...           │ 본문...           │
│ ☑ c.md     │                   │                   │
└────────────┴──────────────────┴──────────────────┘
        ↑ 기둥            ↑ 기둥
```

| 칸 | 기능 |
|---|---|
| 파일 탐색기(제일 왼쪽) | 올린 마크다운 파일 목록. 파일마다 체크박스(인쇄 선택용). 누르면 편집기에 열림 |
| 편집기(가운데) | 메모장처럼 마크다운 원본 작성·수정 |
| 뷰어(오른쪽) | 편집기 내용을 입력하는 대로 바로 보여 줌. 표·코드 블록·체크박스 등 GitHub식 마크다운 지원 |

## 3. 기능

1. **파일 올리기(여러 개 한꺼번에)** — 열기 대화상자에서 여러 파일 선택, 또는 탐색기 칸에 끌어다 놓기. 폴더째 올리기도 지원
2. **새 파일·저장·다른 이름으로 저장** — 수정한 파일은 목록에 표시(●)
3. **스크롤 동기화** — 편집기를 내리면 뷰어도 같은 위치로
4. **인쇄** — 탐색기에서 체크한 여러 파일을 한 번에 인쇄. 인쇄 대화상자는 한 번만 뜨고, 파일마다 새 쪽에서 시작. 뷰어에 보이는 모양 그대로 인쇄. (PDF로 저장도 같은 경로로 가능 — Windows "Microsoft Print to PDF")
5. **크기 조절 기둥** — 세 칸 사이 기둥 두 개, 마지막 크기 기억

## 4. 결정
- 탐색기 = **올린 파일 목록** 방식(교수님 선택 '가', 2026-10-03). 폴더 트리 방식은 채택하지 않음.
- **PDF로 저장 버튼**(교수님 2026-10-03): 프린터(Microsoft Print to PDF)로 만든 PDF가 열리지 않아 별도 기능으로 추가. 한 개면 저장 위치·이름을 고르고, **여러 개면 폴더만 골라 파일마다 '원래 파일 이름.pdf'로 따로 저장**(교수님 2026-10-03, 이름 겹치면 ' (2)', 이미 있으면 덮어쓸지 물음). A4, 여백 15mm, 글자가 살아 있는 PDF. 메뉴·도구 막대 `PDF로 저장`, `Ctrl+Shift+P`
- **서식 버튼(오른쪽 뷰어 위)**(교수님 2026-10-03): 왼쪽 원본에서 선택한 글자에 적용. **뷰어에서 선택해도 원본의 같은 글자를 찾아 적용**(교수님 지적: 뷰어에서 선택하고 누르면 문서 맨 위에 기호가 들어가던 결함 수정, 못 찾으면 원본에서 선택하라고 안내). 같은 버튼을 다시 누르면 해제, 되돌리기 한 번에 취소.
  글자 크기(제목 1~3·본문 / 32·24·18·12px·기본) · 굵게 `**`(Ctrl+B) · 기울임 `*`(Ctrl+I) · 밑줄 `<u>`(Ctrl+U) · 취소선 `~~`.
  밑줄·크기 지정은 마크다운에 문법이 없어 HTML 태그(다른 뷰어에서는 태그가 보이거나 무시될 수 있음). 코드: `src/mdeditor/fmt.py`
- **동시보기**(교수님 2026-10-03): 오른쪽 위 서식 줄 끝 `동시보기` 버튼(켬/끔, `Ctrl+Shift+L`, 보기 메뉴). 켜면 원본·뷰어 **어느 쪽을 스크롤해도** 다른 쪽이 같은 줄로 따라옴, 끄면 각자 따로. 마지막 상태 기억(기본 켬)
- **목록에서 닫기**(교수님 2026-10-03): 체크한 파일을 모두 닫는다(체크가 없으면 지금 보는 파일만, 저장 안 된 것은 물음)
- **텍스트 파일(.txt)**(교수님 2026-10-03): 올리기·폴더 올리기에 포함. 원본 창에만 보이고 뷰어에는 안내문.
  저장하면 같은 이름의 `.md`로 저장되고 그때부터 그 .md가 원본(원래 .txt는 그대로 둠, .md가 이미 있으면 덮어쓸지 물음)
- **상태 표시줄(맨 아래)**(교수님 2026-10-03): 왼쪽 파일 전체 경로(마우스로 선택·복사 가능), 오른쪽 종류(마크다운/텍스트) · 줄/칸·선택 글자 수 · 인코딩·줄바꿈 · 동시보기 상태
- 줄바꿈: 읽을 때 원래 줄바꿈(CRLF/LF)을 기억해 저장 때 되돌린다(이전에는 CRLF 파일이 열자마자 '수정됨'으로 잡히던 결함). 저장 인코딩은 UTF-8
- **목차**(교수님 2026-10-03, 예시 그림 제공): 뷰어 왼쪽에 제목 목록(단계별 들여쓰기), 누르면 그 절로 이동(동시보기면 원본도 따라감), 지금 보는 절 강조. 서식 줄 `목차` 버튼으로 켬/끔(Ctrl+Shift+T), 마지막 상태 기억(기본 켬). 인쇄·PDF에는 안 나옴
- **소스 끄기**(교수님 2026-10-03): 서식 줄 `소스` 버튼(Ctrl+Shift+E)을 끄면 원본 창이 숨고 뷰어만 보임. 다시 켜면 숨기기 전 폭으로. 상태 기억(기본 켬)
- **[모두선택] 토글**(교수님 2026-10-03): 위쪽 도구 줄 `저장` 앞. 누르면 목록 전체 체크, 다시 누르면 전체 해제(일부만 체크돼 있으면 전체 체크). 선택 메뉴·Ctrl+Shift+A
- **설치·이름**(교수님 2026-10-03): 실행 명령 `mdEditor`, uv로 설치(`uv tool install git+https://github.com/KimJin777/markDown`), 처음 실행 때 바탕화면 바로가기 자동 생성(메뉴로 다시 만들기)
- 인쇄 기본 여백 15mm(인쇄 대화상자에서 바꿀 수 있음). 체크한 파일이 없으면 지금 보는 문서만 인쇄할지 묻는다.
