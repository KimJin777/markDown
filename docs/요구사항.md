# markDown — 요구사항·설계안 (2026-10-03)

## 1. 형태
Windows 데스크톱 앱, Python + PySide6 (uv로 관리, 나중에 exe로 묶을 수 있음)

## 2. 화면 (세 칸, 칸 사이 기둥을 잡아 크기 조절)

```
┌────────────┬──────────────────┬──────────────────┐
│ 파일 탐색기 │ 편집기(원본)      │ 뷰어(미리보기)    │
│ ☑ a.md     │ # 제목            │ 제목              │
│ ☐ b.md     │ 본문...           │ 본문...           │
│ ☑ c.md     │                   │                   │
└────────────┴──────────────────┴──────────────────┘
        ↑ 기둥            ↑ 기둥
```

| 칸 | 기능 |
|---|---|
| 파일 탐색기(제일 왼쪽) | 올린 마크다운 파일 목록. 파일마다 체크박스(인쇄 선택용). 누르면 편집기에 열림 |
| 편집기(가운데) | 메모장처럼 마크다운 원본 작성·수정 |
| 뷰어(오른쪽) | 편집기 내용을 입력하는 대로 바로 보여 줌. 표·코드 블록·체크박스 등 GitHub식 마크다운 지원 |

## 3. 기능

1. **파일 올리기(여러 개 한꺼번에)** — 열기 대화상자에서 여러 파일 선택, 또는 탐색기 칸에 끌어다 놓기. 폴더째 올리기도 지원
2. **새 파일·저장·다른 이름으로 저장** — 수정한 파일은 목록에 표시(●)
3. **스크롤 동기화** — 편집기를 내리면 뷰어도 같은 위치로
4. **인쇄** — 탐색기에서 체크한 여러 파일을 한 번에 인쇄. 인쇄 대화상자는 한 번만 뜨고, 파일마다 새 쪽에서 시작. 뷰어에 보이는 모양 그대로 인쇄. (PDF로 저장도 같은 경로로 가능 — Windows "Microsoft Print to PDF")
5. **크기 조절 기둥** — 세 칸 사이 기둥 두 개, 마지막 크기 기억

## 4. 결정
- 탐색기 = **올린 파일 목록** 방식(교수님 선택 '가', 2026-10-03). 폴더 트리 방식은 채택하지 않음.
- **PDF로 저장 버튼**(교수님 2026-10-03): 프린터(Microsoft Print to PDF)로 만든 PDF가 열리지 않아 별도 기능으로 추가. 한 개면 저장 위치·이름을 고르고, **여러 개면 폴더만 골라 파일마다 '원래 파일 이름.pdf'로 따로 저장**(교수님 2026-10-03, 이름 겹치면 ' (2)', 이미 있으면 덮어쓸지 물음). A4, 여백 15mm, 글자가 살아 있는 PDF. 메뉴·도구 막대 `PDF로 저장`, `Ctrl+Shift+P`
- 인쇄 기본 여백 15mm(인쇄 대화상자에서 바꿀 수 있음). 체크한 파일이 없으면 지금 보는 문서만 인쇄할지 묻는다.
